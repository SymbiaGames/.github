# 🎮 Symbia Games

**« Survivre ensemble. Maîtriser pour transmettre. »**

Bienvenue dans l'écosystème Symbia. Nous développons un MMO de survie coopératif où l'économie est un outil au service de l'expérience de jeu, et non une fin en soi.

## 🏗️ Nos dépôts principaux

| Dépôt | Description |
| :--- | :--- |
| [`Symbia`](https://github.com/SymbiaGames/Symbia) | Code source principal du jeu (client, serveur, outils). |
| [`Symbia-Token`](https://github.com/SymbiaGames/Symbia-Token) | Smart contract du token utilitaire `$SYMBIA`. |
| [`.github`](https://github.com/SymbiaGames/.github) | Métadonnées, templates et documentation de l'organisation. |
