# 🤖 Dépôt .github de Symbia Games

Ce dépôt remplit **deux rôles essentiels** pour l'organisation :

## 1️⃣ Il héberge notre site officiel 🌐

Le dossier [`/docs/`](./docs) contient le code source de **https://symbia.games** (via GitHub Pages).

- Configuration GitHub Pages : branche `main`, dossier `/docs`
- Le site présente le jeu, l'économie, la trésorerie, etc.

## 2️⃣ Il contient les métadonnées GitHub de l'organisation 🛠️

- `profile/README.md` : La vitrine affichée sur la page d'accueil de notre organisation GitHub.
- (À venir) `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE/` pour tous nos dépôts.

## ⚠️ Important

- **Ne pas supprimer `/docs`** – c'est le site web en production.
- **Ne pas supprimer `profile/README.md`** – c'est notre carte de visite GitHub.
